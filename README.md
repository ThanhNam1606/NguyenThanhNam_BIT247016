# NguyenThanhNam_BIT247016

This is an Expo React Native app for the course assignment.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

3. Run the project on a device or emulator.

This project includes Expo Router, React Native UI, and the starter app structure generated by create-expo-app.

## Project notes

- App entry: `src/app/index.tsx`
- Screen demo: `src/app/Screen.tsx`
- Navigation is configured with Expo Router
